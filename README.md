# Abhishek Raj — Portfolio

Personal developer portfolio built with pure HTML, modern CSS, and vanilla JavaScript. Features a sleek matte-black theme, high-contrast typography, interactive developer terminal, and showcases engineering builds.

🌐 **Live URL**: [https://abhishekraaj07.github.io](https://abhishekraaj07.github.io)

## 🛠️ Tech Highlights
- Zero Bloat / Zero Dependencies: Single self-contained fast-loading architecture
- Pure Dark Palette: `#070709` matte-black with subtle grid and precision hairline borders
- Responsive & Accessible: WCAG AA contrast, fluid mobile layout
- Interactive Features: 1-click clipboard copy with feedback & live New Delhi (IST) clock
